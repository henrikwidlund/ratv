# Security Policy

## Supported Versions

Only the latest version gets security fixes.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability.
[Report it privately](https://github.com/henrikwidlund/ratv/security/advisories/new).

You get an answer within one week. If not, add a comment to your private report.
The time to fix depends on the problem and on whether it is in third party code.
